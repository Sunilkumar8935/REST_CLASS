# RESTful API - Quora Posts Clone

This project was built as part of my backend web development learning by following my Apnacollege class. It was created to understand RESTful APIs, CRUD operations, Express.js routing, and EJS templating.I am just learning of backend development and finshed restful api and make this quora post .

## Features
- Create a post
- View all posts
- Edit a post
- Delete a post

## Tech Stack
- Node.js
- Express.js
- EJS
- HTML
- CSS
- UUID
- Method Override

## Learning Outcomes
- RESTful API
- CRUD Operations
- Express.js Routing
- EJS Templates
- HTTP Methods (GET, POST, PATCH, DELETE)
